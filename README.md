# Void Stack Website

Public website for **Void Stack**, a relaxing mobile stacking game from Habibi Apps.

The site gives the game a lightweight web presence for players and store visitors and provides the public-facing information needed around the Android release. It is kept separate from the game repository so website and publishing content can be deployed independently.

## Purpose

- Present Void Stack and its core concept
- Support mobile-store traffic with a public product page
- Host release-related and compliance information
- Provide a stable web destination for the game
